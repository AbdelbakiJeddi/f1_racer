PPO, learned on an F1 racer

From the RL problem to tuning and designing your own policy. Numbers read from the project's current config and logs.

A course on PPO built on one real robot: your F1 racer in Isaac Lab. Every idea is derived from first principles, broken in an interactive figure, then found in the project's code.

How each notion is built: problem → derivation → figure → break it (predict first) → why this value → to remember → in the project → deep dive.

To remember. PPO tries slightly different actions, measures which ones paid more than expected, and makes those a bit more likely, never moving the policy too far in one step. Pages 0–4 build everything that sentence needs.
